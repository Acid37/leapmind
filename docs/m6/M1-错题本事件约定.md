# M1 错题本 → M6 画像事件约定

> **版本**: 1.0 | **日期**: 2026-08-09 | **接收方**: M6 画像引擎

## 一、背景

M6 画像引擎的综合学习情况（`LearningSituation`）包含四个来源维度，其中"错题本"（`wrongQuestion`）权重为 **33.2%**，但目前缺少 M1 的事件输入。请 M1 在错题状态变更时向 M6 发送以下事件。

## 二、事件格式

### 接口

```
POST /api/user-profile/{userId}/record-event
Content-Type: application/json
```

该接口已加入 SecurityConfig 白名单，无需 JWT，可直接在服务端发起 HTTP 调用。也可使用 `UserEventService.recordInternal()` 同 JVM 调用（参考 `ReviewReminderServiceImpl.markAsReviewed()`）。

### 请求体

```json
{
  "eventType": "wrong_question_changed",
  "sourceModule": "M1",
  "schemaVersion": "1.0",
  "userId": 1001,
  "kpId": 101,
  "sessionId": null,
  "traceId": null,
  "data": {
    "questionId": 1001,
    "status": "UNRESOLVED",
    "wrongCount": 1
  }
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `eventType` | string | ✅ | 固定值 `"wrong_question_changed"` |
| `sourceModule` | string | ✅ | 固定值 `"M1"` |
| `schemaVersion` | string | ✅ | 固定值 `"1.0"` |
| `userId` | int | ✅ | 用户 ID，≥1 |
| `kpId` | int | ✅ | 知识点的 ID（从 `practice_questions.kp_id` 获取），≥1 |
| `sessionId` | string\|null | 可选 | 答题会话 ID，无则传 `null` |
| `traceId` | string\|null | 可选 | 链路追踪 ID，无则传 `null` |
| `data.questionId` | int | ✅ | 题目 ID（`practice_questions.id`），≥1 |
| `data.status` | string | ✅ | 错题状态，见下表 |
| `data.wrongCount` | int | ✅ | 该题累计错误次数，≥1 |

### data.status 枚举值

| 值 | 含义 | M6 得分映射 |
|----|------|------------|
| `UNRESOLVED` | 尚未复习 | 0.0 |
| `REVIEWING` | 正在复习 | 0.5 |
| `RESOLVED` | 已解决 | 1.0 |

## 三、发送时机

以下时机应发送事件：

1. **首次答错** — `syncMistakeBook()` 创建 `practice_mistakes` 记录时（status=`UNRESOLVED`）
2. **状态变更** — `updateMistakeStatus()` 中 status 实际发生改变时（任一方向转换）
3. **再次答错** — 已解决的错题再次答错，status 重置为 `UNRESOLVED` 时

**注意**: 事件发送应采用 best-effort，失败不应阻塞主流程（catch log 即可）。

## 四、M6 侧如何使用

M6 引擎按以下规则计算 `wrongQuestion` 来源分（0~1）：

1. 取每个 `(kpId, questionId)` 的**最新**事件（按时间，同时取 dbEventId 最大）
2. 将 status 映射为数值：`UNRESOLVED`=0, `REVIEWING`=0.5, `RESOLVED`=1
3. 所有题目的分值求**算术平均**

示例：某知识点下有 3 道错题，状态分别为 UNRESOLVED/REVIEWING/RESOLVED → 得分 = (0+0.5+1)/3 = **0.5**

该得分与其他三来源（answer/question/weakPoint）按权重加权，生成综合学习情况判断。

## 五、完整请求示例

### 首次答错

```bash
curl -X POST http://localhost:8080/api/user-profile/1001/record-event \
  -H "Content-Type: application/json" \
  -d '{
    "eventType": "wrong_question_changed",
    "sourceModule": "M1",
    "schemaVersion": "1.0",
    "userId": 1001,
    "kpId": 101,
    "sessionId": "session-abc",
    "traceId": null,
    "data": {
      "questionId": 5001,
      "status": "UNRESOLVED",
      "wrongCount": 1
    }
  }'
```

### 复习后解决

```bash
curl -X POST http://localhost:8080/api/user-profile/1001/record-event \
  -H "Content-Type: application/json" \
  -d '{
    "eventType": "wrong_question_changed",
    "sourceModule": "M1",
    "schemaVersion": "1.0",
    "userId": 1001,
    "kpId": 101,
    "sessionId": null,
    "traceId": null,
    "data": {
      "questionId": 5001,
      "status": "RESOLVED",
      "wrongCount": 1
    }
  }'
```
