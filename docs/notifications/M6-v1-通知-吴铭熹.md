# M6 v1.0 画像引擎变更通知 — 致吴铭熹（Java 事件采集服务）

> **日期：** 2026-08-05 | **发自：** 张伟涛（M6 画像引擎接口人）

---

## 概要

M6 v1.0 无状态画像引擎已开发完成（221 测试 / 98.2% 覆盖率）。引擎从你维护的 Java 事件采集服务（`192.168.1.19:8080`）获取事件数据。**你的服务是数据流的第一层入口**，需要做以下适配。

---

## 一、数据流架构

```
各模块 → POST /api/events/collect (你的服务) → event_collections 表
       → Java 网关层转换 v1.0 → POST /api/internal/ai/build-profile (Python 引擎)
```

你的服务负责**第一层**（事件采集 + 存储），网关层负责**第二层**（格式转换 + 转发引擎）。两层由吴敏希协调联调。

---

## 二、需要新增模块支持

当前 `LeapMind接口文档(2).md` 只列出了 M1/M2/M4/M7 四个模块。v1.0 引擎需要全部 7 个模块：

| 模块 | 当前状态 | 需要操作 |
|------|:------:|---------|
| M1 | 已支持 | `module="M1"` |
| M2 | 已支持 | `module="M2"` |
| M3 | **未支持** | **新增** `module="M3"`, `eventType="weak_point_changed"` |
| M4 | 已支持 | `module="M4"` |
| M5 | **未支持** | **新增** `module="M5"`, `eventType="lesson_material_used"` |
| M6 | **未支持** | **新增** `module="M6"`, `eventType` 为 `mark_reviewed` / `preference_changed` |
| M7 | 已支持 | `module="M7"` |

**建议**：在 `/api/events/collect` 的 `module` 字段枚举中追加 `"M3"`、`"M5"`、`"M6"`。`eventData` 保持自由 JSON 字符串（各模块友好），格式转换由网关层完成。

---

## 三、event_collections 表需要的字段

当前 `eventData` 是自由 JSON。网关层转为 v1.0 格式时需要各模块在 `eventData` 中提供以下字段：

| 字段 | 可自动生成 | 说明 |
|------|:--------:|------|
| `dbEventId` | ✅ | 直接映射 `event_collections.id` |
| `eventId` | ✅ | 可由 `"evt-{id}"` 生成 |
| `sourceModule` | ✅ | 直接映射 `module` 字段 |
| `schemaVersion` | ✅ | 固定 `"1.0"` |
| `sessionId` | ❌ | 需模块在 eventData 中提供 |
| `kpId` | ❌ | `answer_question` **必填** |
| `traceId` | ❌ | 链路追踪 |
| `occurredAt` | — | 需**包含时区**（如 `+08:00` 或 `Z`） |
