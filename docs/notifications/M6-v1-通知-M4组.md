# M6 v1.0 画像引擎事件接入通知（M4 组）

**致：王成媛（组长）及 M4 即时讲课组全体**

---

## 一、事件类型

M4 组需要向 M6 画像引擎提交以下事件：

| 项目 | 内容 |
|------|------|
| 事件类型 | `lecture_interact`（课堂互动） |
| sourceModule | `"M4"`（必填，固定值） |
| 用途 | 记录用户在课堂中的交互行为 |

---

## 二、事件字段定义

### 2.1 必填字段

| 字段名 | 类型 | 说明 | 格式约束 |
|--------|------|------|----------|
| `lectureId` | string | 课堂ID | `[A-Za-z0-9][A-Za-z0-9._:-]{0,63}` |
| `chapterId` | string | 章节ID | `[A-Za-z0-9][A-Za-z0-9._:-]{0,63}` |
| `action` | enum | 交互动作 | `pause` / `resume` / `replay` / `ask` / `complete` |
| `occurredAt` | string | 事件发生时间 | ISO 8601 带时区，如 `2026-08-05T12:00:00+08:00` |

### 2.2 可选字段（通用）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `sessionId` | string | 会话ID，为 null 时省略不传 |
| `kpId` | string | 知识点ID，为 null 时省略不传 |
| `traceId` | string | 链路追踪ID，为 null 时省略不传 |

---

## 三、事件 JSON 示例

```json
{
  "type": "lecture_interact",
  "sourceModule": "M4",
  "data": {
    "lectureId": "lec_20260805.001",
    "chapterId": "ch3",
    "action": "pause"
  },
  "sessionId": "sess-abc123",
  "occurredAt": "2026-08-05T14:30:00+08:00"
}
```

## 四、特别注意事项

### 4.1 画像计算参与情况

M4 的 `lecture_interact` 事件**当前不参与画像算法计算**，具体含义：

- 不会产生掌握度（mastery）信号
- 不会产生困惑度（confusion）信号
- 不会产生偏好（preference）信号
- 不会产生节奏（pace）信号

### 4.2 全局事件门槛计数

M4 事件**参与全局事件门槛计数**：

- 画像就绪（READY）的门槛是 **至少 5 条有效事件**
- M4 事件会计入这 5 条的门槛
- 典型用途：当其他模块事件不足 5 条时，M4 事件可作为**"填充事件"**帮用户凑满门槛，使画像尽快进入 READY 状态

### 4.3 数据格式要求

- `lectureId` 和 `chapterId` 必须符合正则：`[A-Za-z0-9][A-Za-z0-9._:-]{0,63}`，即以字母或数字开头，后续可包含字母、数字、点号、下划线、冒号、短横线，总长度 1-64 字符
- `action` 必须为枚举值之一，不允许其他值
- `occurredAt` 必须包含时区信息（如 `+08:00`），不传时区的 ISO 时间将被拒绝

## 五、常见错误预防

| 错误场景 | 错误做法 | 正确做法 |
|----------|----------|----------|
| null 字段显式传递 | `"sessionId": null` | 直接省略该字段 |
| 额外字段 | data 中包含 `studentName` 等未定义字段 | data 对象仅包含上述定义的字段 |
| ID 格式 | `lectureId` 为空字符串或以特殊字符开头 | 以字母或数字开头，长度 1-64 |
| 时区缺失 | `"occurredAt": "2026-08-05T12:00:00"` | `"occurredAt": "2026-08-05T12:00:00+08:00"` |
| action 拼写 | `"action": "paused"` | `"action": "pause"`（原形动词） |
