# M2 事件上报答疑

> 回复：阳睿 | 日期：2026-08-08

## Q1：reasonTag 从哪来？映射是否合理？

**你的映射建议完全合理，采用。**

M6 v1.0 契约定义 `request_explanation` 的 `reasonTag` 取值（来源：`LearningEventPolicy.java`）：

| 枚举值 | 含义 | 前端触发场景 |
|------|------|------|
| `WRONG_ANSWER` | 答错后请求讲解 | 从错题本进入讲题 |
| `REPEATED_ERROR` | 同一道题反复错误 | 同题累计答错 ≥2 次后进入讲题 |
| `USER_REQUEST` | 学生主动请求 | 拍照答疑、主动点"问老师" |
| `LOW_CONFIDENCE` | 学生表示不确定 | 点"没信心/不确定"后请求讲解 |
| `REVIEW_NEEDED` | 复习需要 | 从复习提醒入口进入讲题 |

> 旧系统的 `concept_unclear` / `careless` / `formula_wrong` 是 M7 的 `confusionTag`，和 M2 的 `reasonTag` 是不同的字段，不要混用。

## Q2：repeatCount（重复查看次数）怎么算？

**`repeatCount` 是提交 `explanation_feedback` 时的字段，表示同一次讲题被"重新讲解"的次数。**

计数逻辑：

```
学生请求讲题     → request_explanation (explainId="exp-001")
学生点"重新讲解"  → 前端内部计数器 +1
学生再点"重新讲解" → 计数器 +1
学生提交反馈     → explanation_feedback (explainId="exp-001", repeatCount=2)
```

- 第一次讲解对应的 feedback 里 `repeatCount=0`
- 前端需要维护当前 explainId 的重新讲解计数器
- 取值范围：0-100

## Q3：拍照答疑（PhotoQAPage）要不要上报？

**要上报，算 `request_explanation`。**

| 字段 | 值 |
|------|------|
| eventType | `request_explanation` |
| reasonTag | `USER_REQUEST` |
| explainId | 拍照答疑的 contentId（不满足格式则前端生成） |

`explainId` 格式要求：`[A-Za-z0-9][A-Za-z0-9._:-]{0,63}`（以字母或数字开头，1-64字符）。

## 上报示例

### 讲题页 — 请求讲解

```json
{
  "eventId": "evt_m2_1723123456_a3f2",
  "userId": 23,
  "eventType": "request_explanation",
  "sourceModule": "M2",
  "occurredAt": "2026-08-08T10:00:00+08:00",
  "schemaVersion": "1.0",
  "kpId": 101,
  "traceId": "trace-m2-001",
  "data": {
    "explainId": "exp-20260808-001",
    "reasonTag": "WRONG_ANSWER"
  }
}
```

### 讲题页 — 提交反馈

```json
{
  "eventId": "evt_m2_1723123500_b7e1",
  "userId": 23,
  "eventType": "explanation_feedback",
  "sourceModule": "M2",
  "occurredAt": "2026-08-08T10:05:00+08:00",
  "schemaVersion": "1.0",
  "kpId": 101,
  "traceId": "trace-m2-002",
  "data": {
    "explainId": "exp-20260808-001",
    "feedback": "understood",
    "repeatCount": 2
  }
}
```

### feedback 枚举值

| 值 | 含义 | 权重 |
|------|------|:--:|
| `understood` | 理解了 | -2.0 |
| `partly_understood` | 部分理解 | 0.5 |
| `still_confused` | 仍然困惑 | 2.0 |
