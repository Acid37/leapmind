# M6 v1.0 画像引擎变更通知 — 致欧俊濠（M6 前端 + M8 虚拟教师）

> **日期：** 2026-08-05 | **发自：** 张伟涛（M6 画像引擎接口人）

---

## 概要

M6 v1.0 无状态画像引擎已开发完成。你负责的 M6 前端页面（用户学习档案页 + 知识点掌握度详情页）需要适配新的 API 响应结构。

---

## 一、API 变更

### 旧接口已删除

| 接口 | 状态 |
|------|:----:|
| `POST /api/review/calculate-all` | **已删除**（404） |
| `POST /api/events/process` | **已删除**（404） |

### 新画像数据来源

画像数据现在通过 `POST /api/internal/ai/build-profile` 获取（Java 网关层调用后写入画像查询 API）。前端仍通过 GET 查询接口获取数据（保留不变）：
- `GET /api/user-profile/{userId}/knowledge-status`
- `GET /api/user-profile/{userId}/timeline`

---

## 二、新的 Profile 数据结构

```json
{
  "preferredContentModes": ["video"],
  "preferredExplanationStyle": "step_by_step",
  "learningPace": "moderate",
  "recentFocus": [{"kpId": 101, "weight": 1.0}],
  "recentConfusions": [{
    "kpId": 101, "detail": "概念不理解",
    "evidenceCount": 2, "confidence": 0.4
  }],
  "summaryProfile": "综合学习情况稳定…（150-300字摘要）",
  "confidence": 0.67
}
```

| 字段 | 类型 | 说明 | 页面用途 |
|------|------|------|---------|
| `preferredContentModes` | `string[]` | 偏好内容类型 | 学习档案页偏好展示 |
| `preferredExplanationStyle` | `string` | 偏好讲解风格 | 同上 |
| `learningPace` | `string` | 学习节奏 slow/moderate/fast | 指标卡片 |
| `recentFocus` | `array` | 近期关注知识点（最多5个，含权重） | 知识树高亮 |
| `recentConfusions` | `array` | 近期困惑（最多5个，标准化标签） | 困惑卡片 |
| `summaryProfile` | `string` | 150-300字学习情况摘要 | 档案页顶部摘要区 |
| `confidence` | `float` | 画像置信度 0-0.95 | 可信度提示 |

## 三、新的 KnowledgeMastery 结构

```json
{
  "kpId": 101,
  "masteryScore": 0.85,
  "masteryStatus": "MASTERED",
  "confidence": 0.75,
  "evidenceCount": 15,
  "trend": "IMPROVING",
  "algorithmVersion": "m6-profile-v1.0.0"
}
```

### masteryStatus 五种状态

| 状态 | 含义 | 建议视觉 |
|------|------|---------|
| `MASTERED` | 已掌握 | 绿色 / 实心星 |
| `BASIC_MASTERY` | 基本掌握 | 浅绿 / 半实心星 |
| `CONSOLIDATING` | 巩固中 | 黄色 / 进度条 |
| `WEAK` | 薄弱 | 红色 / 警告 |
| `INSUFFICIENT_EVIDENCE` | 证据不足 | 灰色 / 虚线 |

### trend 三种趋势

| 趋势 | 含义 | 建议图标 |
|------|------|---------|
| `IMPROVING` | 改善中 | ↗ 绿色 |
| `STABLE` | 稳定 | → 蓝色 |
| `DECLINING` | 下降中 | ↘ 红色 |

## 四、前端页面影响

### 用户学习档案页
- 雷达图：用 `masteryScore` + `masteryStatus` 替换旧的 `review_stage` + `mastered` 布尔值
- 知识树：`recentFocus` 高亮近期关注节点
- 新增：`summaryProfile` 作为档案页顶部摘要
- 新增：`recentConfusions` 作为困惑卡片展示

### 知识点掌握度详情页
- 进度条：用 `masteryScore`（0-1 连续值）替代旧的二值 mastered
- 趋势箭头：用 `trend` 字段
- 证据数量：`evidenceCount` 可作为"答题次数"展示
- 置信度：`confidence` 可作为"可信度"提示

---

## 五、不受影响的部分
- M8 虚拟教师（TTS + Three.js/Live2D）不受本次变更影响
- 复习提醒卡片逻辑不变
- 事件采集逻辑在后端，前端无感知
