
## 六、各模块事件类型速查

| 模块 | eventType | 必填字段 |
|:----:|------|------|
| M1 | `answer_question` | `isCorrect(bool)`, `difficulty(1-5)`, `timeSpentSec`, `hintCount`, `kpId` |
| M1 | `finish_practice` | `questionCount`, `accuracy(0-1)`, `durationSec` |
| M2 | `request_explanation` | `explainId`, `reasonTag` |
| M2 | `explanation_feedback` | `explainId`, `feedback` |
| M3 | `weak_point_changed` | `oldScore(0-1)`, `newScore(0-1)`, `reason` |
| M4 | `lecture_interact` | `lectureId`, `chapterId`, `action` |
| M5 | `lesson_material_used` | `contentId`, `materialType`, `result` |
| M6 | `mark_reviewed` | `result`, `timeSpentSec`, `hintCount` |
| M6 | `preference_changed` | `preferenceKey`, `preferenceValue` |
| M7 | `ask_doubt` | `topic`, `confusionTag`, `isFollowUp(bool)` |

> 所有事件都必须包含公共字段：`eventId`, `userId`, `eventType`, `sourceModule`, `occurredAt`(含时区), `schemaVersion:"1.0"`, `kpId`(可选), `sessionId`(可选), `traceId`(可选)
