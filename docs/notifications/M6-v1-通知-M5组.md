# M6 v1.0 画像引擎事件接入通知（M5 组）

**致：谢兴坤（组长）及 M5 AI备课组全体**

---

## 一、事件类型

M5 组需要向 M6 画像引擎提交以下事件：

| 项目 | 内容 |
|------|------|
| 事件类型 | `lesson_material_used`（课程材料使用） |
| sourceModule | `"M5"`（必填，固定值） |
| 用途 | 记录用户对备课材料的使用情况 |

---

## 二、事件字段定义

### 2.1 必填字段

| 字段名 | 类型 | 说明 | 格式约束 |
|--------|------|------|----------|
| `contentId` | string | 内容ID | `[A-Za-z0-9][A-Za-z0-9._:-]{0,63}` |
| `materialType` | enum | 材料类型 | `text` / `image` / `audio` / `video` / `exercise` |
| `result` | enum | 使用结果 | `completed` / `skipped` / `helpful` / `not_helpful` |
| `occurredAt` | string | 事件发生时间 | ISO 8601 带时区，如 `2026-08-05T12:00:00+08:00` |

### 2.2 可选字段（通用）

| 字段名 | 类型 | 说明 |
|--------|------|------|
| `sessionId` | string | 会话ID，为 null 时省略不传 |
| `kpId` | string | 知识点ID，为 null 时省略不传 |
| `traceId` | string | 链路追踪ID，为 null 时省略不传 |

---

```json

  "type": "lesson_material_used",

  "data": {
```

## 四、特别注意事项

### 4.1 当前画像计算参与情况（重要！）

M5 的 `lesson_material_used` 事件**当前被窗口过滤排除**，这意味着：

- **不参与画像算法计算**（不产生掌握度/困惑度/偏好/节奏信号）
- **不参与全局事件门槛计数**（不计入 READY 画像所需的 5 条事件）
- **不参与任何画像输出**

### 4.2 格式校验仍然执行

尽管 M5 事件当前不参与画像计算，但**事件格式校验仍然生效**：

- 契约校验层会对每个 M5 事件进行格式校验
- 格式错误的事件会被拒绝，返回 **HTTP 400** 错误
- **当前最低要求：确保事件格式正确，不做任何业务约束**

### 4.3 后续规划（提前知悉）

M5 事件未来将纳入画像计算，规划方向如下：

- 利用率最高的 `materialType` 可作为 `preferredContentModes`（用户偏好内容模式）的**隐式推断来源**
- 届时会提前通知，不影响当前已上报的事件格式
- 建议从现在就开始规范化上报，避免后续返工

## 五、常见错误预防

| 错误场景 | 错误做法 | 正确做法 |
|----------|----------|----------|
| null 字段显式传递 | `"kpId": null` | 直接省略该字段 |
| 额外字段 | data 中包含 `fileName` 等未定义字段 | data 对象仅包含上述定义的字段 |
| contentId 格式 | 空字符串或特殊字符开头 | 以字母或数字开头，长度 1-64 |
| materialType 拼写 | `"materialType": "excercise"` | `"materialType": "exercise"` |
| result 值错误 | `"result": "finished"`（不在枚举中） | `"result": "completed"` |
| 时区缺失 | `"occurredAt": "2026-08-05T12:00:00"` | `"occurredAt": "2026-08-05T12:00:00+08:00"` |
