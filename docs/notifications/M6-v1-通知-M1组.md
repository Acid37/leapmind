# M6 v1.0 画像引擎 -- M1 组事件接入通知

**致：刘楷钦、杜恩泽、龙智森、孔维诚 及 M1 组全体**

---

## 一、背景

M6 v1.0 无状态画像引擎已开发完成。引擎从各模块的 Java 事件采集服务获取事件数据，进行用户画像计算（掌握度趋势、薄弱点识别、困惑分析、近期关注等）。

请 M1 组各位按照以下规范提交事件数据。

---

## 二、需要提交的事件类型

M1 组需要提交以下 **2 种** 事件：

| 事件类型 | 说明 | 负责人 |
|---|---|---|
| `answer_question` | 逐题答题事件（学生每做一道题即上报） | 杜恩泽、刘楷钦 |
| `finish_practice` | 完成练习事件（一次练习结束后上报汇总） | 龙智森 |

---

## 三、事件格式规范

### 3.1 通用字段（两个事件都需包含）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `eventType` | string | 是 | `"answer_question"` 或 `"finish_practice"` |
| `sourceModule` | string | 是 | **必须填 `"M1"`**，不能填其他值 |
| `userId` | string | 是 | 学生用户 ID |
| `sessionId` | string | 是 | 练习会话 ID，同一练习会话内的事件共享相同 sessionId |
| `kpId` | string | 是（answer_question）/ 建议（finish_practice） | 知识点 ID，关联到具体知识点 |
| `occurredAt` | string (ISO 8601) | 是 | 事件发生时间，**必须包含时区信息**，例如 `2026-08-05T12:00:00+08:00` |

### 3.2 `answer_question` 专属字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `isCorrect` | **boolean** | 是 | 该题是否答对。**必须是 JSON 布尔值 `true`/`false`，绝对不能是整数 `1`/`0`** |
| `difficulty` | int | 是 | 题目难度等级，范围 1-5 |
| `timeSpentSec` | int | 是 | 答题耗时（秒），范围 0-86400 |
| `hintCount` | int | 是 | 提示使用次数，范围 0-100 |
| `confusionTag` | string | 否 | 困惑标签（如有），用于困惑分析 |

### 3.3 `finish_practice` 专属字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `questionCount` | int | 是 | 本次练习题目总数，范围 1-10000 |
| `accuracy` | float | 是 | 本次练习正确率，范围 0-1（例如 0.85 表示 85%） |
| `durationSec` | int | 是 | 练习总耗时（秒），范围 0-86400 |

## 四、特别注意事项

### 4.1 `isCorrect` 必须是布尔值 —— 最常见错误！

```json
// 正确
{ "isCorrect": true }
{ "isCorrect": false }

// 错误 -- 禁止使用整数！
{ "isCorrect": 1 }
{ "isCorrect": 0 }
```

**引擎内部使用 JSON Schema 严格校验，整数 `1`/`0` 会导致事件被拒绝。**

### 4.2 `kpId` 必须填写

`answer_question` 事件的 `kpId` **必填**，否则引擎无法将答题数据关联到知识点，该题的掌握度计算将失效。

### 4.3 `finish_practice.accuracy` 去重规则

当同一 `sessionId` 下同时存在 `answer_question` 逐题事件时，`finish_practice` 中的 `accuracy` 字段**会被引擎去重忽略**（引擎优先使用逐题数据自行计算正确率，以保证精度一致）。`questionCount` 和 `durationSec` 仍会正常使用。

### 4.4 `occurredAt` 时区信息

`occurredAt` **必须包含时区信息**（如 `+08:00`），不能使用纯 UTC 或无时区的本地时间。否则事件时间排序可能错乱，导致掌握度趋势计算偏差。

```json
// 正确
"occurredAt": "2026-08-05T12:00:00+08:00"

// 错误 -- 缺少时区
"occurredAt": "2026-08-05T12:00:00"
```

### 4.5 事件上报接口

所有事件统一通过 Java 事件采集服务上报：

```
POST /api/events/collect
Content-Type: application/json

{
  "module": "M1",
  "events": [ ... ]
}
```

## 五、事件 JSON 示例

### `answer_question` 示例

```json
{
  "eventType": "answer_question",
  "sourceModule": "M1",
  "userId": "student_001",
  "sessionId": "sess_20260805_001",
  "kpId": "kp_quadratic_equation_001",
  "occurredAt": "2026-08-05T12:00:00+08:00",
  "eventData": {
    "isCorrect": false,
    "difficulty": 3,
    "timeSpentSec": 120,
    "hintCount": 1,
    "confusionTag": "公式记忆混淆"
  }
}
```

### `finish_practice` 示例

```json
{
  "eventType": "finish_practice",
  "sourceModule": "M1",
  "userId": "student_001",
  "sessionId": "sess_20260805_001",
  "occurredAt": "2026-08-05T12:30:00+08:00",
  "eventData": {
    "questionCount": 10,
    "accuracy": 0.7,
    "durationSec": 1800
  }
}
```

## 六、常见错误预防清单

- [ ] `isCorrect` 确认使用 JSON 布尔值 `true`/`false`，非整数
- [ ] `sourceModule` 确认填写 `"M1"`
- [ ] `answer_question.kpId` 确认已填写
- [ ] `occurredAt` 确认包含时区信息（`+08:00`）
- [ ] `difficulty`、`timeSpentSec`、`hintCount` 确认在取值范围内
- [ ] `accuracy` 确认使用 0-1 的小数形式，非百分数
