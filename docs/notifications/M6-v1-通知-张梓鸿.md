# M6 v1.0 画像引擎升级通知

**致：张梓鸿（M6 Java 事件采集API + 画像查询API）**

---

## 一、变更概述

M6 v1.0 无状态画像引擎已完成重写（221测试/98.2%覆盖率），本次升级对你的 API 层有以下重大影响。

## 二、具体变更

### 2.1 旧接口删除

以下两个接口已删除，调用方将收到 **404**：

| 接口 | 状态 |
|---|---|
| `POST /api/review/calculate-all` | 已删除 |
| `POST /api/events/process` | 已删除 |

所有依赖这两个接口的客户端需迁移到新的画像计算入口。

### 2.2 新画像计算入口

画像计算统一通过 Python 引擎提供：

```
POST /api/internal/ai/build-profile
```

这是一个内部接口，由 Python 无状态引擎直接暴露，不走 Java 网关层。网关层负责读事件 → 调引擎 → 标记已处理。

### 2.3 v1.0 请求格式（严格契约）

```json
{
  "contractVersion": "1.0",
  "requestId": "uuid-string",
  "userId": "string",
  "mode": "FULL",
  "baseProfileVersion": null,
  "fromEventIdExclusive": null,
  "eventWatermarkInclusive": "2025-01-01T00:00:00Z",
  "events": [
    {
      "dbEventId": 12345,
      "eventId": "string",
      "sourceModule": "M2",
      "schemaVersion": "1.0",
      "eventType": "answer_submitted",
      "sessionId": "uuid-string",
      "kpId": "string",
      "traceId": "uuid-string",
      "timestamp": "2025-01-01T12:00:00Z",
      "eventData": { }
    }
  ]
}
```

关键字段说明：
- `mode`：`FULL`（全量重建）或 `INCREMENTAL`（增量更新）
- `contractVersion`：固定 `"1.0"`，用于引擎校验兼容性
- `requestId`：每次调用方生成唯一 UUID，用于链路追踪
- `events` 数组：每个事件需包含 `dbEventId`、`eventId`、`sourceModule`、`schemaVersion`、`sessionId`、`kpId`、`traceId` 等公共字段（部分可由网关自动生成）

### 2.4 v1.0 响应格式（三态可辨识联合）

响应通过 `status` 字段区分三种状态：

| status | 含义 | 触发条件 | 响应体 |
|---|---|---|---|
| `READY` | 画像计算成功 | 事件数量 >= 5 | 含完整 `profile` + `knowledgeMastery` |
| `INSUFFICIENT_DATA` | 数据不足 | 事件数量 1-4 | 仅返回状态码和提示信息 |
| `NO_CHANGE` | 无新事件 | 事件数量 = 0 | 仅返回状态码 |

`READY` 状态下完整响应结构：

```json
{
  "status": "READY",
  "algorithmVersion": "m6-profile-v1.0.0",
  "profile": {
    "preferredContentModes": ["video", "text"],
    "preferredExplanationStyle": "detailed",
    "learningPace": "moderate",
    "recentFocus": ["二次函数"],
    "recentConfusions": [...],
    "summaryProfile": "...",
    "confidence": 0.85
  },
  "knowledgeMastery": [
    {
      "kpId": "string",
      "algorithmVersion": "m6-profile-v1.0.0",
      "masteryScore": 0.75,
      "masteryStatus": "PROFICIENT",
      "confidence": 0.9,
      "evidenceCount": 12,
      "trend": "IMPROVING"
    }
  ]
}
```

### 2.5 画像查询 API 适配

你需要更新以下接口以适配新的响应结构：

- `GET /api/user-profile/{userId}` — 用户画像查询
- `GET /api/user-profile/{userId}/knowledge-status` — 知识点掌握状态查询

新旧结构的关键差异：
- `algorithmVersion` 字段新增在响应顶层和每个知识掌握结果中
- 画像字段重组为 `profile` 对象，不再平铺
- 掌握状态新增 `masteryStatus`、`confidence`、`evidenceCount`、`trend` 字段
